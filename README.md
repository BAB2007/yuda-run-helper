# 宇达步道乐跑助手

河北工程大学校园跑（步道乐跑）的自动化测试客户端。

> **仅供个人学习与接口联调使用。** 身体是自己的，能跑还是跑一跑。

---

## 这是什么

一个**不依赖 Gradle** 的 Android 小工具。跑前把一张人脸自拍存进本机，
跑步时按校园路网生成一条闭环路线、逐点上报位置与配速，收尾把轨迹 / 截图 /
陀螺仪三段文件传上去，让这一次跑步在服务端成为一条**数据完整、速度像真人**的记录。

## 怎么编译

```bash
python build_apk.py
```

一条命令串完 `aapt2 compile → aapt2 link → javac → d8 → zipalign → apksigner`。

需要：

* **JDK 11+** —— `javac` / `keytool` 在 PATH 里
* **Android SDK** —— `build-tools/36.0.0` 和 `platforms/android-37.0/android.jar`
  （默认从 `%LOCALAPPDATA%\Android\Sdk` 读，见 `build_apk.py` 开头几行）

两个坑写在脚本注释里了，这里也提一句：

1. **改版本号要改三处** —— `app/AndroidManifest.xml`、`app/res/values/strings.xml`、
   `build_apk.py`。`aapt2 link` 的 `--version-code/--version-name` 会被 Manifest 里的值盖掉。
2. **aapt2 不支持中文路径** —— 所以脚本先把源码镜像到 `%TEMP%\ledao_apk_build` 再编译。

签名用的密钥第一次运行时会自动生成在 `work/keys/`（**那个文件不要外传**）。

## 怎么用

1. 装 APK → 侧边栏「🔐 安装抓包证书」→ 系统弹窗点「确定」（只需一次）
2. 首页「🧑 设置人脸照片」选一张正脸自拍（**原图直存**，不裁剪、不压缩、不做任何检测）
3. 点「▶ 开始跑步」—— 之后全自动：
   抓身份 → 建隧道 → 生成路线 → 逐点上报 → 收尾成单
4. 出问题就点「📋 复制日志」

「复制日志」会一次性复制**全部原始日志**，只把个人标识（uid / 学号 / 设备号 /
登录令牌）换成【已隐藏】，签名、时间戳、里程、坐标、服务端响应一律原样保留 ——
可以直接发出去让人排查。

> ⚠️ 跑步期间**不要同时打开步道乐跑**。它是单会话登录，两边同时在线会互相顶掉。
