## 如何下载使用

**视频教程**：预留，还没录制。

**文字说明**：进入 <https://github.com/BAB2007/yuda-run-helper>（国内打不开就用
<https://gitee.com/BAB2007/yuda-run-helper>）后点击右上角的 **Code** 按钮，
选择 **Download ZIP**，下载完成后解压即可。

不想下整个压缩包的话，直接进
[`宇达步道乐跑助手/`](https://github.com/BAB2007/yuda-run-helper/blob/main/宇达步道乐跑助手/) 目录点那个 APK，再点 **Download raw file** 就行。
**仓库里只留一份安装包，文件名带版本号** —— 当前版本：**v1.0.34**，
文件名 `宇达步道乐跑助手-v1.0.34.apk`。装完打开，**标题栏右侧就是版本号**，
对不上就是下到了旧的（下到了旧的按 `Ctrl+F5` 强刷一次页面）。

打开解压出来的 APK 一路允许即可。因为这个是煮波个人项目，所以没有应用商城许可，
所以需要手动允许，校友不坑校友，请放心。

**首次启动会有点乱，按这个顺序点**：

| 弹出来的 | 怎么点 |
|---|---|
| 「开发者留言」窗口 | 首次要停够 30 秒才能关（点「关闭」）；不想再看可以勾上「未来都不弹出此窗口」 |
| 「要允许 … 发送通知吗」 | 点**允许**（跑步时靠通知看进度） |
| 「网络连接请求 / VPN」 | 点**确定**（只问一次，用来抓一次你自己的登录令牌） |
| 跟「证书」有关的系统提示 | 点**确定**装上；装完系统可能再警告一句「网络可能被监控」之类的话，那是装抓包证书之后的正常提示，**关闭**就行 |

**然后**：

1. 点 **📲 自动提取** —— 它会带你到步道乐跑转一圈，把你的用户标识取回来
   （只有这一步会跳到步道乐跑；助手**不会自己跳到别的 App 里**）
2. 点 **🧑 设置人脸照片** —— 选一张你自己的正脸自拍（原图直存，不裁剪不压缩）
3. 点 **▶ 开始跑步** —— 之后全自动：确认令牌 → 生成路线 → 逐点上报 → 收尾成单

**支持后台自动运行**，您在此期间可以去做您自己的事情：可以切到别的 App、可以息屏，
**从最近任务里划掉也不会停**（要停请回到助手点「■ 停止跑步」）。

**切走时右上角会缩出一个小窗**（v1.0.32 起）：给一次「悬浮窗」权限之后，你切到别的 App，
助手会在屏幕右上角留一个手指大小的窗口。它有两个用处：
**有可见窗口的进程，系统的省电策略一般不动它**（比求 ROM 高抬贵手靠谱得多），
而且**它在不在动一眼就能看出来**。

* **在跑步**（v1.0.34 起）：第一行就是 **正在跑 04:00**（用时），下面两行是
  里程进度 / 配速 / 打卡数，点 `停` 要按两下才真停（防口袋误触）。
  **它不会再喊"卡了"** —— 有跑友看到那句「卡了」来问"我跑得好好的为什么说卡了"，
  那只是助手自己慢了半拍，说成"出事了"是描述错了（v1.0.34 改掉）；
* **没在跑**（v1.0.33 起也挂）：上面是 **未开跑** + **学期目标 N 次 · 已完成 M 次**，
  最下面那行是当前时间 —— **秒还在跳就说明助手没被冻住**；真被冻过，
  第三行会多一个「❄卡12s」这样的小记号（助手要是真歇了几秒，
  才在配速那一行尾巴上写一句，60 秒后自己消失）；
* 小窗能拖走、点 `－` 收起、点 `⤢` 回到助手；没在跑时第三个键是 `✕`（收起小窗）；
* **字不会被切掉**（v1.0.34）：窗口宽度是按这一屏最长的那行字**现量**出来的，
  所以把系统字体调大也不怕 —— 之前写死 176dp，字体一大「已完成 M 次」就被切掉了一截。

它只需要一次「悬浮窗」权限、Android 6 以上都有，不挑机型；息屏那一段它帮不上忙
（屏幕黑了窗口不算可见），那一段靠的是前台服务 + 唤醒锁。

第一次用请点首页那行 **🪟 迷你小窗**，按里面的五步走一遍：
① 开「悬浮窗」权限；② 看一眼它长什么样；③ 「切走自动缩窗」开关（默认开）；
④ 万一这台机器连小窗一起冻 —— 点这个按钮打开系统那层的「自启动 / 后台活动」页，
把助手全部放开（小米 / 华为 / 荣耀这类的省电策略还要设成「无限制」）；
⑤ 把状态写进日志，出问题连日志一起发过来。

> v1.0.33 起首页那行「🔋 后台运行设置」已经删掉了 —— 后台这件事从此只有小窗这一条路
> （原来那套「电池优化白名单 + 90 秒后台体检」真机实测对国产 ROM 基本没用：白名单加了照样冻，
> 体检也只能事后告诉你"被冻了"，不如小窗从源头解决）。

> 万一系统还是把助手冻住了（荣耀 / 华为 / 小米只要没放开后台都会这样），助手也不会白跑：
> 日志里会出现「⚠ 系统把助手冻住了 X 秒」，**这段被冻住的时间会自动从「用时」里剔除**，
> 配速不会被拖坏，回来接着跑完就行。

如遇问题请复制日志并发到我的邮箱（煮波最近有些忙可能回复不及时，但有时间一定会回复）：
**3855962053@qq.com** —— 「📋 复制日志」会一次性复制全部原始日志，
只把个人标识（uid / 学号 / 设备号 / 登录令牌）换成【已隐藏】，
签名、时间戳、里程、坐标、服务端响应一律原样保留，**可以直接发出来**。

## 原理介绍

**一句话**：助手不定位、也不用你跑 —— 它按官方协议把这一场“报”上去，
服务器收到的东西和真跑一次没有区别。

**步道乐跑怎么记一次跑步**

1. 你在校园里真的跑，手机 GPS 实时定位；
2. App 每几秒采一个点（经纬度 / 时间 / 步频），边跑边发；
3. 路过打卡点自动打卡 —— 打卡点是起跑那一刻从 14 个点里随机抽 2 个；
4. 中途随机弹一次人脸核验，停下来现场自拍；
5. 跑完上传三段文件：轨迹 + 地图截图 + 传感器数据；
6. 服务器按规则判定（单次 2~10 km、配速 3'~8'、打卡 ≥2 个、人脸通过），计入成绩。

**助手怎么做**

你只做两件事：装一次证书、存一张自己的自拍。剩下的助手来：

1. 从本机乐跑里取一次登录令牌（不用账号密码）；
2. 按校园路网生成一条闭环路线，每一拍的坐标与速度先算好（加减速是连续的，像真人）；
3. 用**官方同一套签名与加密**，按同样的节拍逐点上报；
4. 路过打卡点照样打卡；中途刷脸就用你存的那张自拍走同一套核验；
5. 收尾照样上传那三段文件。

![步道乐跑与助手原理对比](https://github.com/BAB2007/yuda-run-helper/raw/main/doc/principle-compare.png)

![报文层：两边发出去的是同一种请求](https://github.com/BAB2007/yuda-run-helper/raw/main/doc/principle-protocol.png)

**所以**

* 记录是真进了官方服务器的，官方 App / 官网里查得到，不是本地假数据；
* 助手**没有自己的服务器**，也不经过任何第三方 —— 报文从你手机直接发给步道乐跑的接口；
* 它只作用于**你本机已经登录的那个账号**，替不了别人跑；
* 也正因为它复刻的是“客户端自述”，服务端那些规则（里程、配速、打卡、人脸）一条都省不掉。

想深挖技术细节的看这几条：

* 抓包**不需要绕证书固定** —— 乐跑给自己的域名放开了用户证书信任，装一张普通用户证书就能看明文；
* 请求有**两套并存的 MD5 签名**、两套 **AES-128-CBC** 密钥，而密钥常量就明文躺在 `libjni_utils.so` 里；
* 风控令牌 `lpi0` / `lpi1` 是 `Base64(AES-CBC(umid + md5hex(时间戳)))`，键名 `lpi1` 在两处含义完全不同（这是最容易踩的坑）；
* 打卡点不是服务端分配的，是客户端自己抽签、再用 `setRunLocationRecord.point_ids` 告诉服务端。

## 顺手一提：这个仓库里没有你的个人信息

发布前把三处都扫过一遍（`work/_piscan.py`，v1.0.33 加的）：

* **要发布出去的这套文件**（README / 使用说明 / LICENSE / .gitignore / build_apk.py / app/ / doc/）：
  没有 uid、学号、登录令牌、真名、人脸照片、抓包文件；
* **仓库里那个 APK**（解压后逐条目搜可读串）：同样没有；
* **两个仓库的全部历史**（`git rev-list --all` 逐个提交 grep，删掉的文件也在这条路里）：同样没有。

源码里只留下两处**设备指纹**常量（`umid` 兜底值、官方 App 那个 `mobileDeviceId`），
它们是**真在用**的（手机没有 root 时 lpi1 得靠兜底值、现场取标识靠它判"扫到的这个是不是真的"），
注释里已经不再抄写它们；取舍与扫描方法记在开发笔记里。
另外两样是**作者故意公开**的：开发者留言里的联系方式、以及下面那个收款码。
