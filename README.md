# 宇达步道乐跑助手

两个版本，按自己的学校挑一个装；**包名不同，可以同时装**，互不覆盖。

| | 版本 | 给谁用 | 安装包 |
|---|---|---|---|
| A | **河工程版 v1.0.65** | 河北工程大学（方向、打卡点走本校那套） | [下载](宇达步道乐跑助手/宇达步道乐跑助手-v1.0.65.apk) |
| B | **通用版 v5.0.14**（主仓库：<https://github.com/BAB2007/budalepao-run-helper>） | 其他学校 / 想自己画路线 | [下载](宇达步道乐跑助手_通用版/宇达步道乐跑助手_通用版-v5.0.14.apk)（本仓库里这份是同版本的过渡副本，老链接不会失效） |

安卓 7.0 以上直接装。装完**标题栏右侧就是版本号**，对不上就是下到了旧的（`Ctrl+F5` 强刷页面）。

## 怎么用（通用版四步）

| 顺序 | 点什么 | 干什么 |
|---|---|---|
| ① | **🧑 人脸上传** | 按本校要求把照片传好（本校不扫脸就不用管） |
| ② | **📲 提取令牌** | 跳一次步道乐跑取回身份，等到「已就绪 ✅」 |
| ③ | **🗺 规划路线** | 在地图上自己画一条线，线要经过本场必过的打卡点 |
| ④ | **▶ 开始跑步** | 之后全自动：开跑、逐点上报、收尾成单 |

**每跑完一场都要重画线、换打卡点**；同一张照片 10 天内重复用会被拦下（务必户外、正脸、原图直传）。

河工程版步骤一样，只是**路线自动生成、不用画**，细节见 [使用说明.md](使用说明.md)。

## 三条硬规矩

1. 开跑前把**步道乐跑从后台划掉**，跑的中途也别再打开（单会话登录，同时在线会互相顶）。
2. **不要息屏**，也别切走太久；切走会缩成右上角小窗，第一行秒数还在跳就是在跑。
3. 通用版**只跑你画的那条线**（左右 1 米），不会自己乱跑。
